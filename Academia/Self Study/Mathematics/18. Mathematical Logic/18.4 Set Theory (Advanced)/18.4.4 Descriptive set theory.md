## Definition

**Descriptive set theory** studies definable sets of real numbers — Borel sets, analytic sets, and beyond — classified by how they're built from open sets using countable unions, intersections, and complements or projections.

---

## The Borel Hierarchy

Starting from open sets, close under countable union ($\Sigma$) and complement ($\Pi$), producing an increasing hierarchy $\Sigma^0_\alpha, \Pi^0_\alpha$ indexed by countable ordinals — all Borel sets appear at some countable stage.

---

## Analytic and Projective Sets

An **analytic set** ($\Sigma^1_1$) is the continuous image of a Borel set; **projective sets** extend this by alternating projections and complements. Regularity properties (measurability, the perfect set property) hold for analytic sets in ZFC alone, but proving them for the *full* projective hierarchy requires large cardinal assumptions — connecting directly to [[18.4.3 Large cardinals]].

> [!tip] Why regularity properties matter
> "Every set in this class is Lebesgue measurable" or "has the perfect set property" are exactly the kind of statements that, for pathological sets built via the Axiom of Choice, can genuinely fail — descriptive set theory finds the boundary where definability guarantees good behavior.
