## ZFC Axioms

**Zermelo–Fraenkel set theory with Choice (ZFC)** is the standard foundation for mathematics, built from a short list of axioms about the single primitive relation $\in$:

| Axiom | Informal meaning |
|-------|-------------------|
| Extensionality | Sets with the same elements are equal |
| Pairing | $\{a,b\}$ exists for any $a,b$ |
| Union | $\bigcup A$ exists for any set $A$ |
| Power Set | $\mathcal P(A)$ exists |
| Infinity | An infinite set exists |
| Separation | $\{x \in A : \varphi(x)\}$ exists (per formula $\varphi$) |
| Replacement | The image of a set under a definable function is a set |
| Foundation | Every nonempty set has an $\in$-minimal element (no infinite descending $\in$-chains) |
| Choice | Every family of nonempty sets has a choice function |

---

## Why Axiomatize?

Naive set theory (any collection is a set) leads to **Russell's Paradox**: $R = \{x : x \notin x\}$ gives $R \in R \iff R \notin R$. ZFC's Separation axiom only builds subsets of *already-existing* sets, blocking the paradox — $R$ simply isn't a set.

> [!warning] Foundation blocks self-membership
> The Foundation axiom rules out $x \in x$ entirely, so paradoxes built on self-membership can't even be stated as sets in ZFC.

## Practice Problems

1. Show Russell's paradox using unrestricted comprehension, and explain why Separation avoids it.
2. Explain why Replacement is needed even though Separation exists (consider building $\{f(n) : n \in \mathbb{N}\}$ for a fast-growing $f$).
3. What does the Axiom of Infinity assert, and why can't it be derived from the others?
