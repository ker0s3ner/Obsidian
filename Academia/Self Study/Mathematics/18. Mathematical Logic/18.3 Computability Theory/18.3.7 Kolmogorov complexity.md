## Definition

The **Kolmogorov complexity** $K(x)$ of a string $x$ is the length of the shortest program (in a fixed universal language) that outputs $x$:

$$K(x) = \min\{|p| : U(p) = x\}$$

A string is **random** (incompressible) if $K(x) \gtrsim |x|$ — no shorter description exists than $x$ itself.

---

## Invariance Theorem

The choice of universal machine $U$ only shifts $K(x)$ by a bounded additive constant (independent of $x$), so "shortest description length" is well-defined up to $O(1)$ regardless of programming language.

---

## Uncomputability of K

> [!warning] $K$ is not computable
> There is no algorithm that computes $K(x)$ for arbitrary $x$. If there were, one could construct a program exploiting this to output a string provably more complex than the program itself — a direct analogue of the [[18.3.1 Turing machines|Halting Problem]]'s diagonalization (the "Berry paradox" made rigorous).

## Practice Problems

1. Explain why $K(x) \leq |x| + O(1)$ always holds (consider the trivial "print this literal string" program).
2. Sketch why computing $K$ would let you construct a paradoxical self-referential program.
3. What does it mean for a string to be "Kolmogorov random," and why can no algorithm generate infinitely many verified examples?
