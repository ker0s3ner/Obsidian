## Statement

> [!example] Rice's Theorem
> Let $P$ be any **nontrivial** semantic property of the function a Turing machine computes (nontrivial: some machines have it, some don't; semantic: depends only on the function computed, not the machine's code). Then $\{\langle M \rangle : M \text{'s function has property } P\}$ is **undecidable**.

---

## Why "Semantic" Is Essential

> [!warning] Syntactic properties can be decidable
> "Does $M$'s code contain more than 100 states?" is a *syntactic* property (about the machine's description, not its behavior) — perfectly decidable. Rice's theorem only forbids deciding properties of the **function computed**.

---

## Applications

Rice's theorem immediately shows the following are all undecidable: "does $M$ compute the zero function," "does $M$ halt on all inputs," "does $M$ compute a total function," "is $M$'s language regular" — essentially any interesting behavioral question about programs.
