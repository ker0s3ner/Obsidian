## Overview

Elementary number theory studies integers using only elementary techniques — no algebraic structures beyond $\mathbb{Z}/n\mathbb{Z}$, no complex analysis. It's the launching point for [[17.2 Algebraic Number Theory]] and [[17.3 Analytic Number Theory]].
