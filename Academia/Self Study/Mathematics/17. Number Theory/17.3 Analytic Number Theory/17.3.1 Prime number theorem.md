## Statement

Let $\pi(x)$ denote the number of primes $\leq x$. The **Prime Number Theorem (PNT)** states:

$$\pi(x) \sim \frac{x}{\ln x} \qquad \text{as } x \to \infty$$

meaning $\lim_{x\to\infty} \dfrac{\pi(x)}{x/\ln x} = 1$.

---

## Equivalent Forms

| Form | Statement |
|------|-----------|
| Density | The "probability" a random integer near $x$ is prime is $\approx 1/\ln x$ |
| $\vartheta(x)$ | Chebyshev's function $\vartheta(x) = \sum_{p \leq x} \ln p \sim x$ |
| $\psi(x)$ | Von Mangoldt's $\psi(x) = \sum_{p^k \leq x} \ln p \sim x$ |

---

## Connection to the Zeta Function

The PNT is equivalent to the statement that $\zeta(s)$ has **no zeros on the line $\text{Re}(s) = 1$** — proved independently by Hadamard and de la Vallée Poussin (1896) using this exact fact. See [[17.3.2 Riemann zeta function]].

> [!note] The Riemann Hypothesis sharpens this
> PNT gives $\pi(x) = \text{Li}(x) + o(x/\ln x)$. The Riemann Hypothesis (zeros on $\text{Re}(s) = 1/2$) would sharpen the error term to $O(\sqrt x \ln x)$ — vastly better than what's currently proven.

## Practice Problems

1. Estimate $\pi(10^6)$ using the PNT approximation and compare to the true value ($78498$).
2. Show that $\vartheta(x) \sim x$ and $\pi(x) \sim x/\ln x$ are equivalent via partial summation.
3. Explain (informally) why zeros of $\zeta(s)$ on $\text{Re}(s)=1$ would break the PNT.
4. Why is $\text{Li}(x) = \int_2^x \frac{dt}{\ln t}$ a better approximation to $\pi(x)$ than $x/\ln x$?
