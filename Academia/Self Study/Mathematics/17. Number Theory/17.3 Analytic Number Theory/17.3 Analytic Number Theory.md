## Overview

Analytic number theory applies tools from complex analysis and Fourier analysis to problems about integers, especially the distribution of primes.

> Every file circles the same theme: primes look random locally but are governed by a precise analytic object ($\zeta(s)$ or an L-function) globally — and every open problem here (RH, twin primes, Goldbach) is about how tightly that control can be pinned down.
