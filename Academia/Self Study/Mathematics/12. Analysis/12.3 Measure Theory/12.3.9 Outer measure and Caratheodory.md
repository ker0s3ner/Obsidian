## Outer Measure

An **outer measure** $\mu^*$ on a set $X$ assigns a value in $[0,\infty]$ to *every* subset of $X$ (not just measurable ones), satisfying:

1. $\mu^*(\emptyset) = 0$
2. Monotonicity: $A \subseteq B \implies \mu^*(A) \leq \mu^*(B)$
3. Countable subadditivity: $\mu^*\left(\bigcup_n A_n\right) \leq \sum_n \mu^*(A_n)$

**Example — Lebesgue outer measure**:

$$\mu^*(A) = \inf\left\{\sum_k \ell(I_k) : A \subseteq \bigcup_k I_k, \ I_k \text{ open intervals}\right\}$$

---

## Carathéodory's Criterion

A set $E$ is **Carathéodory measurable** if for every $A \subseteq X$:

$$\mu^*(A) = \mu^*(A \cap E) + \mu^*(A \setminus E)$$

i.e. $E$ "splits" every test set additively.

> [!tip] Why this definition works
> This criterion is purely set-theoretic — it doesn't reference open sets or intervals — yet the collection of measurable sets it produces is always a $\sigma$-algebra, and $\mu^*$ restricted to it is always a genuine countably additive measure.

---

## Carathéodory's Extension Theorem

The collection $\mathcal{M}$ of Carathéodory-measurable sets is a $\sigma$-algebra, and $\mu = \mu^*|_{\mathcal{M}}$ is a complete measure. Applied to the interval-cover outer measure above, this **constructs Lebesgue measure** from scratch.

More generally: any **premeasure** on an algebra of sets extends via this construction to a full measure on the generated $\sigma$-algebra — this is how Lebesgue–Stieltjes measures are built from distribution functions.

---

## Non-Measurable Sets

Not every subset of $\mathbb{R}$ is Lebesgue measurable — the **Vitali set**, built using the Axiom of Choice from cosets of $\mathbb{Q}$ in $[0,1)$, fails Carathéodory's criterion.

## Practice Problems

1. Verify that $\mu^*(\mathbb{Q} \cap [0,1]) = 0$ using the interval-cover definition.
2. Show that any set with $\mu^*(E) = 0$ is automatically Carathéodory measurable.
3. Prove countable additivity of $\mu^*$ restricted to measurable sets follows from the Carathéodory criterion.
4. Explain why the Vitali set construction requires the Axiom of Choice.
