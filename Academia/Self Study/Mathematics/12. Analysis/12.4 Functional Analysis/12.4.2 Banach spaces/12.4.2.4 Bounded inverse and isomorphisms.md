## Isomorphisms of Banach Spaces

A linear map $T: X \to Y$ between Banach spaces is a **(topological) isomorphism** if it is a bounded linear bijection with bounded inverse — equivalently, there exist $c, C > 0$ with

$$c\|x\| \leq \|Tx\| \leq C\|x\| \quad \text{for all } x \in X$$

---

## Bounded Inverse Theorem

> [!example] Consequence of the Open Mapping Theorem
> If $T: X \to Y$ is a bounded linear **bijection** between Banach spaces, then $T^{-1}$ is automatically bounded.

So on Banach spaces, checking that a linear bijection is bounded in one direction is enough — boundedness of the inverse is free. This can fail badly if either space is incomplete.

## Practice Problems

1. Show that if $T$ is an isomorphism, $\|T\|\cdot\|T^{-1}\| \geq 1$, with equality iff $T$ is a scalar multiple of an isometry.
2. Give an example of a bounded linear bijection between incomplete normed spaces whose inverse is unbounded.
3. Show that isomorphism of Banach spaces preserves completeness and separability.
