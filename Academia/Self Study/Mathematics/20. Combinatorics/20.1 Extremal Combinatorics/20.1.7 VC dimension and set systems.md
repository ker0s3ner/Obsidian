## Shattering

A set system $\mathcal{F} \subseteq \mathcal{P}(X)$ **shatters** a subset $S \subseteq X$ if every subset of $S$ arises as $F \cap S$ for some $F \in \mathcal{F}$. The **VC dimension** of $\mathcal{F}$ is the size of the largest set it shatters.

---

## Sauer–Shelah Lemma

> [!example] Sauer–Shelah Lemma
> If $\mathcal{F}$ has VC dimension $d$ on a ground set of size $n$, then:
> $$|\mathcal{F}| \leq \sum_{i=0}^{d} \binom{n}{i}$$

This is a fundamental "phase transition" result: bounded VC dimension forces $\mathcal{F}$ to be polynomially (not exponentially) sized in $n$.

> [!tip] Why this matters in learning theory
> VC dimension is exactly the right combinatorial notion controlling how many examples are needed to learn a concept class in statistical learning theory — bounded VC dimension is equivalent to learnability (Vapnik–Chervonenkis theory).

## Practice Problems

1. Compute the VC dimension of the set of half-lines $\{[a,\infty) : a \in \mathbb{R}\}$ on $\mathbb{R}$.
2. Verify the Sauer–Shelah bound for a family of VC dimension 1 on $n=4$ points.
3. Explain why intervals on $\mathbb{R}$ have VC dimension 2.
4. Relate the Sauer–Shelah lemma to sample complexity bounds in machine learning.
