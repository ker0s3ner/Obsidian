## The Core Idea

To prove an object with property $P$ exists, define a random object and show:

$$\Pr[\text{object has property } P] > 0$$

If the probability is positive, some object in the sample space must satisfy $P$ — no explicit construction is needed.

---

## Example: Lower Bound for Ramsey Numbers

**Claim**: $R(k,k) > 2^{k/2}$ for $k \geq 3$.

Color the edges of $K_n$ randomly (each edge red/blue independently with probability $1/2$). The expected number of monochromatic $K_k$'s is:

$$\binom{n}{k} \cdot 2^{1-\binom{k}{2}}$$

For $n = \lfloor 2^{k/2}\rfloor$, this expectation is $< 1$, so some coloring has **zero** monochromatic $K_k$'s — proving $R(k,k) > n$.

> [!tip] The method proves existence, not construction
> The probabilistic method shows a good coloring exists without ever exhibiting one explicitly — this is often the *only* known approach for these bounds.

## Lovász Local Lemma

A refinement handling cases where "bad events" are individually rare but not independent — if each bad event has low probability and depends on few others, a positive-probability outcome avoiding all of them still exists.
