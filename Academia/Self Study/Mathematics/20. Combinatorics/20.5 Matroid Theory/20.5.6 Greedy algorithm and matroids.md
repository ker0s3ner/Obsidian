## Matroid Optimization Problem

Given a matroid $M=(E,\mathcal{I})$ and a weight function $w: E \to \mathbb{R}$, find a basis maximizing total weight.

---

## The Greedy Algorithm

Sort elements by decreasing weight; add each element to the current set if doing so keeps it independent. This produces a **maximum-weight basis** — provably optimal, not just a heuristic.

> [!example] Kruskal's algorithm is this greedy algorithm
> For the graphic matroid, this exact procedure — add the next cheapest edge if it doesn't create a cycle — is precisely Kruskal's minimum spanning tree algorithm. Its correctness is a special case of matroid greedy optimality.

---

## Matroids Are Exactly the Structures Where Greedy Works

A remarkable converse (Rado, Edmonds): if $(E,\mathcal{I})$ is a hereditary set system where greedy always finds an optimal weighted basis for **every** weight function, then $(E,\mathcal{I})$ must be a matroid. Matroids are the precise combinatorial characterization of "greedy-friendly" independence systems.

## Practice Problems

1. Run the greedy algorithm on a small weighted graph to confirm it reproduces Kruskal's MST.
2. Prove that greedy produces a maximum-weight independent set using the exchange axiom.
3. Give an example of a non-matroid hereditary set system where greedy fails to be optimal.
4. Explain the significance of the Rado–Edmonds converse for recognizing matroid structure.
