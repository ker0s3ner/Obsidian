## Definition

A **topological invariant** is a property or object assigned to a space that is preserved by homeomorphisms: if $X \cong Y$, they must have the same invariant. Invariants are the main tool for proving two spaces are **not** homeomorphic.

---

## Basic Invariants

| Invariant | Type | Preserved because |
|-----------|------|--------------------|
| Compactness | Boolean | Continuous image of compact is compact |
| Connectedness | Boolean | Continuous image of connected is connected |
| Number of connected components | Integer | Components map to components |
| Metrizability | Boolean | Defined purely topologically |
| Cardinality | Number | Bijections preserve cardinality |

> [!example] Using invariants together
> $[0,1]$ and $(0,1)$ agree in cardinality and connectedness, but $[0,1]$ is compact while $(0,1)$ is not — this single invariant is enough to rule out a homeomorphism.

---

## Algebraic Invariants

More refined invariants assign an *algebraic object* (group, ring) to a space, so that homeomorphic spaces get isomorphic objects:

- **Fundamental group** $\pi_1(X)$ — see [[14.1.2 Fundamental group]]
- **Homology groups** $H_n(X)$ — see [[14.2.1 Homology]]
- **Euler characteristic** $\chi(X)$

These distinguish spaces that agree on all the "soft" invariants above — e.g. a circle and a disk are both compact and connected, but $\pi_1(S^1) \cong \mathbb{Z} \neq \{0\} \cong \pi_1(D^2)$.

## Practice Problems

1. Use compactness to show $\mathbb{R}$ is not homeomorphic to $[0,1]$.
2. Use connectedness to show $\mathbb{R} \setminus \{0\}$ is not homeomorphic to $\mathbb{R}$.
3. Explain why the number of connected components is a topological invariant.
4. Why can't compactness alone distinguish a circle from a disk?
5. Look ahead to [[14.1.2 Fundamental group]]: what invariant finally distinguishes the circle from the disk?
