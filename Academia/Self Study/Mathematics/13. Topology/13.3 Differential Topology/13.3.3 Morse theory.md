## Morse Functions

A smooth function $f : M \to \mathbb{R}$ is a **Morse function** if all its critical points (where $df_p = 0$) are **non-degenerate**: the Hessian $H_f(p)$ is invertible.

The **index** of a non-degenerate critical point is the number of negative eigenvalues of the Hessian — the number of independent directions in which $f$ decreases.

---

## The Morse Lemma

Near a non-degenerate critical point $p$ of index $k$, there are local coordinates in which:

$$f(x) = f(p) - x_1^2 - \cdots - x_k^2 + x_{k+1}^2 + \cdots + x_n^2$$

So near any critical point, $f$ looks exactly like a standard quadratic saddle — no higher-order terms matter.

---

## Topology from Critical Points

> [!example] Passing a critical point changes the topology
> As $t$ increases past a critical value $f(p) = c$ of index $k$, the sublevel set $M_{\leq t} = \{x : f(x) \leq t\}$ changes homotopy type by **attaching a $k$-cell**.

This gives $M$ a CW structure (see [[13.2.6 CW complexes (intro)]]) with one $k$-cell per index-$k$ critical point — the foundation for computing homology from a Morse function.

**Example**: the height function on a torus standing on end has 4 critical points of indices $0, 1, 1, 2$, matching the torus's CW structure.

---

## Morse Inequalities

If $c_k$ is the number of index-$k$ critical points and $b_k = \dim H_k(M)$ the Betti numbers:

$$b_k \leq c_k \qquad \text{for all } k$$

with equality in total alternating sum: $\sum_k (-1)^k c_k = \chi(M)$.

## Practice Problems

1. Find the critical points and their indices for the height function on a standard torus embedded in $\mathbb{R}^3$.
2. Verify the Morse Lemma's local form for $f(x,y) = x^2 - y^2$ near the origin.
3. Use the Morse inequalities to show $\chi(S^n)$ matches the standard two-critical-point Morse function on the sphere.
4. Explain why non-degeneracy of critical points is essential for the Morse Lemma to hold.
