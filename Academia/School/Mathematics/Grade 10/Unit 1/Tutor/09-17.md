## Test (Image 1)

### 3. 3x² + 11x + 6 = 0

- D = 11² − 4·3·6 = 121 − 72 = 49, √D = 7
- x = (−11 ± 7) / 6

**Answer:** x₁ = −2/3, x₂ = −3

### 4. Substitution: x = 4 + 3y, xy − 2y = 1

- Substitute: (4 + 3y)y − 2y = 1 → 3y² + 2y − 1 = 0
- D = 4 + 12 = 16 → y = (−2 ± 4) / 6 → y = 1/3 or y = −1
- y = 1/3 → x = 5
- y = −1 → x = 1

**Answer:** (5; 1/3) and (1; −1)

### 5. 2x² − 7x + 3 = 0

- D = 49 − 24 = 25, √D = 5
- x = (7 ± 5) / 4

**Answer:** x₁ = 3, x₂ = 1/2

### 6. Addition: 6x − 2y = 12, 3x + y = 0

- Multiply the second equation by 2: 6x + 2y = 0
- Add the two equations: 12x = 12 → x = 1
- y = −3x = −3

**Answer:** (1; −3)

## Systems (Image 2)

### a) x = 5y, 10/x + 3/y = 5

- 10/(5y) + 3/y = 2/y + 3/y = 5/y = 5 → y = 1
- x = 5

**Answer:** (5; 1)

### c) y = x − 4, 10/x + 6/(4 − y) = 0

- 4 − y = 8 − x, so 10/x + 6/(8 − x) = 0
- Multiply by x(8 − x): 10(8 − x) + 6x = 0 → 80 − 4x = 0 → x = 20
- y = 16 (restrictions x ≠ 0, x ≠ 8 satisfied)

**Answer:** (20; 16)

### e) x − y = −5, 4/x + 6/y = 5

- y = x + 5, so 4/x + 6/(x + 5) = 5
- Multiply by x(x + 5): 4(x + 5) + 6x = 5x(x + 5)
- 10x + 20 = 5x² + 25x → x² + 3x − 4 = 0 → x = 1 or x = −4
- x = 1 → y = 6 (check: 4 + 1 = 5 ✓)
- x = −4 → y = 1 (check: −1 + 6 = 5 ✓)

**Answer:** (1; 6) and (−4; 1)
